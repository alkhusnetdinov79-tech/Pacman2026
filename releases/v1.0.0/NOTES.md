Pacman2026 1.0.0 — игра в стиле Pacman для РЕД ОС 8 / RHEL 8.

Четыре призрака, бонусы, уровни, три жизни, сохранение рекорда и шесть оригинальных звуковых эффектов.

Установка:
```sh
sudo dnf install ./pacman2026-1.0.0-1.el8.noarch.rpm
pacman2026
```

Зависимости: Python 3.6+, python3-tkinter, alsa-utils. Пакет noarch, не подписан.
Проверены 11 тестов, графический запуск пакета с Tk 8.6 и звуки через ALSA null.
Тестирование непосредственно на РЕД ОС 8 не выполнялось.
