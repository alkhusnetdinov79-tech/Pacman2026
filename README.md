# Pacman2026

Игра в стиле Pacman для рабочего стола РЕД ОС 8 / RHEL 8. Оригинальные
лабиринт, графика и синтезированные звуки; сторонние игровые ресурсы не используются.
Python 3.6+, Tk 8.6, ALSA. Интернет при игре не требуется.

## Установка RPM на РЕД ОС 8

Скачайте `pacman2026-1.0.0-1.el8.noarch.rpm`, перейдите в каталог загрузки:

```sh
sudo dnf install ./pacman2026-1.0.0-1.el8.noarch.rpm
pacman2026
```

DNF установит зависимости `python3`, `python3-tkinter` и `alsa-utils` из
репозиториев ОС. Запускайте игру от обычного пользователя в графической сессии.
Ярлык добавляется в меню «Игры». Для звука необходимы доступное звуковое
устройство ALSA и включённая громкость. Проверка:
`aplay -q /usr/share/pacman2026/assets/sounds/start.wav`.
При отсутствии звукового устройства игра продолжает работать без звука.
Пакет не подписан; контрольные суммы находятся в `SHA256SUMS`.

## Управление и правила

- Enter — начать игру / следующий уровень / продолжить после потери жизни.
- Стрелки или WASD — движение; поддерживается русская раскладка ЦФЫВ.
- Пробел или P — пауза; потеря фокуса окна тоже включает паузу.
- M — включить/выключить звук; R — новая игра; Esc — выход.

Собирайте точки (10 очков) и большие бонусы (50 очков). Бонус на время
позволяет съесть призраков: 200, 400, 800, 1600 очков подряд. За все точки
уровня — 1000 очков. Три жизни, четыре призрака с разными целями, каждый
уровень немного быстрее. Рекорд сохраняется в
`${XDG_STATE_HOME:-~/.local/state}/pacman2026/score.json`.

## Разработка и сборка

Используйте существующий checkout; отдельный worktree не нужен.

```sh
python3 tools/generate_sounds.py
python3 -m pacman2026.app
python3 -m unittest discover -s tests -v
```

Сборка на РЕД ОС / RHEL (потребуются пакеты `rpm-build`, `python3`):

```sh
sudo dnf install rpm-build python3
sh tools/build_rpm.sh
```

В `dist/` появятся RPM, исходный SRPM и `SHA256SUMS`. Пакет `noarch`
содержит исходный Python-код и WAV/SVG, без нативных библиотек и байткода
машины сборки. Gzip payload выбран для совместимости со старым RPM.
Проверка интерфейса на машине с Xvfb:
`xvfb-run -a python3 -m pacman2026.app --smoke-test`.
